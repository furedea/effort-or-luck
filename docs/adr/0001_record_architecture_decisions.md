# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-15

In the context of a solo project that will be resumed across many sessions, facing decisions whose reasons are not visible in the code, we decided for short Architecture Decision Records under `docs/adr/` and against keeping rationale only in Issues and PR descriptions, to achieve a single place to find why the project is shaped the way it is, accepting the small cost of writing one file per broad decision.
