# effort-or-luck

A browser game about job hunting in Japan. One hundred versions of you, each with a different allowance from home, live the same year from April of the third year of university to June 1st of the fourth. Every choice you make is attempted by all of them, and at the end you can keep their luck fixed and change only how they chose.
